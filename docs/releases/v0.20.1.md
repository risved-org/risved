# v0.20.1 — Bun 1.4.3

Bun projects now build and run with Bun 1.4.3, upgraded from 1.3.14. This resolves the startup version check failure from `@sveltejs/adapter-bun`, which requires Bun 1.4 or newer.

Update Risved, then redeploy affected projects with Bun selected under **Settings → Build & Runtime**. Existing deployment images keep their original Bun version until rebuilt. Custom build and start commands must use Bun when required by the application.

## Release procedure

After the release PR is merged and required checks pass, run the **Release** workflow on `main` with `expect_version=0.20.1`. Verify the GitHub release, container image, and risved.com version manifest.
