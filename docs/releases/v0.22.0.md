# v0.22.0 — More JavaScript frameworks

Risved now detects current TanStack Start projects using `@tanstack/react-start` or `@tanstack/solid-start`, alongside the legacy `@tanstack/start` package. Current projects should configure Nitro's Node server preset and produce `.output/server/index.mjs`.

New deployment templates cover Elysia, React Router framework mode, and AdonisJS:

- Elysia builds to `dist/index.js`. Choose Bun for Bun applications, or Node.js with Elysia's Node adapter and a Node-targeted build.
- React Router builds with `react-router build` and runs `@react-router/serve` with the server output. The routing library alone does not trigger framework detection.
- AdonisJS uses Node 24 for both build and runtime. It starts inside the standalone build directory with production dependencies available. The Node 24 builder is created on demand and refreshed on deployment when older than seven days, including on upgraded servers.

Existing frameworks retain their Node 22 runtime defaults. Existing containers are unchanged until redeployed. No database migration is required.
