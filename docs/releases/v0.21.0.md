# v0.21.0 — Node and Bun deployments

Risved now focuses on Node.js and Bun. Deno runtime support, hybrid Node/Deno templates, Fresh and Lume detection, and the Deno-based Fresh and Hono starter presets have been removed.

Astro uses `@astrojs/node` in standalone mode, runs `dist/server/entry.mjs`, and includes production dependencies. Configure `output: 'server'` and `adapter: node({ mode: 'standalone' })` in your Astro project. The default container port is 3000, matching Risved's proxy and health checks.

Hono applications use the generic Node/Bun path: provide a package manifest and build script, then set the start command for your application's entrypoint. SvelteKit and generic projects retain the Bun 1.4.3 option released in v0.20.1.

This release removes supported deployment paths. Existing application containers are not restarted by the upgrade. Reconfigure any old Deno-specific adapters or custom commands before redeploying. No project data is deleted.

The public framework guides and marketing pages are updated separately alongside this release.

## Release procedure

After required checks and review pass, merge the release PR and run the Release workflow on main with expect_version=0.21.0. Publish the matching documentation update after the image is available.
